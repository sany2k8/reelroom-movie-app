# Contributing to ReelRoom Movie App

Thank you for considering contributing! We welcome bug reports, feature requests, and pull requests.

How to contribute

1. Fork the repository and create a branch named like `feature/short-description` or `fix/short-description`.
2. Make your changes in the branch. Follow the coding style already used in the project.
3. Run tests and linters before submitting a PR.
4. Open a pull request against the `community-files` branch or the default branch as appropriate. Describe your changes and include any relevant issue numbers.

Pull request checklist

- [ ] My code follows the project style
- [ ] I have added/updated tests where applicable
- [ ] I have updated documentation if necessary
- [ ] I have run the test suite and it passes

Commit message format

- Use present tense: "Add feature", "Fix bug"
- Include a short, descriptive title and, optionally, a longer body explaining the change.

Issue reporting

Use the bug report and feature request issue templates in .github/ISSUE_TEMPLATE/.

Code review

Be responsive to review comments and update your PR as requested. Small changes may be merged quickly; larger design changes may require more discussion.
