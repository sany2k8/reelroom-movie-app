# Security Policy

If you discover a security vulnerability in this project, please report it privately to: sany2k8dev@gmail.com

Do not create a public issue for security vulnerabilities.

What to include in your report
- A clear description of the vulnerability
- Steps to reproduce
- Impact and severity
- Any suggested fixes or mitigation steps

Response
- We will acknowledge receipt within 72 hours.
- We will work to evaluate and remediate the issue and coordinate disclosure.
